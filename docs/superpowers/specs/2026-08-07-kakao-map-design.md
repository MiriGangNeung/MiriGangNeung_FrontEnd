# 카카오맵 전환 설계

## 목표

코스 결과 화면의 Leaflet/OpenStreetMap 지도를 카카오맵 JavaScript SDK로 교체한다. 카드와 핀 선택, 경로 표시 등 현재 지도 기능은 유지한다.

## 적용 범위

- `VITE_KAKAO_MAP_API_KEY` 환경변수로 카카오맵 SDK를 불러온다.
- `CourseMap`의 입력값인 `courseStops`, `activeIndex`, `onSelect`는 변경하지 않는다.
- 코스 순서대로 모든 장소에 번호 핀을 표시한다.
- 전달받은 장소 배열의 순서대로 카카오맵 `Polyline`을 그린다.
- 첫 지도 표시 시 모든 핀이 보이도록 여유 공간을 둔 경계를 계산해 지도 배율과 중심을 설정한다.
- 코스 카드를 선택하면 해당 장소로 지도를 이동하고, 핀을 선택하면 해당 카드가 선택되도록 한다.

## 구성과 상태 흐름

`CourseMap`은 카카오맵 SDK 로드와 지도 객체 생성을 담당한다. 선택된 코스 순서는 상위 컴포넌트의 기존 `activeStop` 상태를 그대로 사용한다.

핀 클릭 시 `onSelect(index)`를 호출한다. 상위 상태가 변경되어 `activeIndex`가 내려오면 활성 핀의 모양을 갱신하고, 해당 장소로 지도 중심과 배율을 이동한다. 따라서 카드와 지도는 하나의 선택 상태를 공유한다.

SDK 로더는 모듈 단위 Promise로 한 번만 실행한다. `autoload=false`로 스크립트를 요청한 뒤 `kakao.maps.load`에서 지도를 생성하여 React Strict Mode에서도 스크립트 태그가 중복되지 않게 한다.

## 세부 동작

1. SDK 로드가 완료되면 코스 장소로 지도, 핀, 폴리라인, 전체 경계를 생성한다.
2. 모든 장소를 포함하는 `LatLngBounds`에 여백을 추가하여 초기 지도 화면을 맞춘다.
3. 유효한 `activeIndex`가 전달되면 활성 핀을 강조하고, 그 장소를 카카오맵 레벨 5로 이동한다.
4. 선택된 장소가 없으면 전체 코스 경계로 돌아간다.
5. 각 핀을 클릭하면 해당 장소의 인덱스를 `onSelect`로 전달한다.

## 오류 처리

환경변수 키가 없거나 SDK 로드에 실패하면 지도 영역에 간단한 한글 안내 문구를 표시한다. 이 경우에도 코스 목록은 계속 사용할 수 있다.

## 검증 기준

- 순서 기반 좌표와 전체 코스 경계 입력을 만드는 순수 함수를 단위 테스트한다.
- 관련 테스트, 린트, 프로덕션 빌드를 실행한다.
- 브라우저에서 네 개의 핀이 모두 기본 화면에 보이는지 확인한다.
- 폴리라인이 코스 카드 순서와 같은 순서로 연결되는지 확인한다.
- 카드 선택이 해당 핀으로 지도를 이동시키는지, 핀 선택이 해당 카드를 활성화하는지 확인한다.
