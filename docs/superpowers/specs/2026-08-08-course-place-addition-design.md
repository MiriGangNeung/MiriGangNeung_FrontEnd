# 코스 결과: 장소 검색 및 동선 추가

## 목표

`/course-result`에서 사용자가 새 장소를 검색하고 지도에서 위치를 확인한 뒤, 현재 코스의 마지막 정거장으로 추가할 수 있게 한다.

## 사용자 흐름

1. 왼쪽 코스 목록의 `새로운 장소 추가`를 누른다.
2. 코스 제목과 태그 아래, 기존 정거장 목록 위에 장소 추가 패널이 열린다.
3. 사용자가 장소명·지역·태그를 검색하면 기존 `PLACES` 데이터에서 일치하는 결과만 보인다.
4. 결과를 선택하면 해당 장소가 오른쪽 카카오맵에서 활성 핀으로 표시되고 지도 중심이 그 위치로 이동한다.
5. `코스에 추가`를 누르면 선택 장소가 마지막 정거장으로 확정되고, 목록의 순번·시간과 지도 핀·경로가 갱신된다.
6. 패널을 닫거나 선택을 취소하면 코스는 바뀌지 않는다.

## 설계

### 데이터

- `Place`에 지도 표시에 필요한 `lat`, `lng`를 추가한다.
- 기존 장소 데이터에 실제 강릉 좌표를 채운다.
- `CourseResultPage`가 서버에서 받은 초기 코스를 로컬 상태로 복사해, 현재 세션의 사용자 추가 정거장을 관리한다.
- 선택 장소로부터 마지막 정거장을 만드는 순수 헬퍼를 둔다. 이 헬퍼는 중복 장소를 추가하지 않고, 순번은 마지막 번호 다음, 시간은 기존 마지막 시간에서 90분 뒤로 정한다. 기본 체류 시간은 60분, 혼잡도는 `mid`다.

### UI 컴포넌트

- `CourseResult`에 `isPlaceAdderOpen`, 검색어, 선택 장소를 관리하는 장소 추가 패널을 둔다.
- 패널은 검색 input, 결과 목록, 선택 상태, 취소 및 `코스에 추가` 버튼으로 구성한다.
- 기존 코스에 포함된 장소는 결과에서 비활성화하고 `이미 코스에 있어요`를 표시한다.
- 검색 결과를 선택하는 것은 지도 미리보기만 바꾸며, 코스 변경은 명시적인 `코스에 추가`로만 발생한다.

### 지도 연동

- 선택한 검색 장소는 임시 `CourseStop`으로 변환해 `CourseMap`에 전달한다.
- 미리보기일 때는 마지막 핀을 활성 상태로 표시하고 지도 중심을 해당 핀으로 이동한다.
- 확정 시 임시 정거장이 실제 코스 상태에 저장되어 카카오맵 핀과 도보 경로가 다시 계산된다.

## 오류 및 빈 상태

- 검색 결과가 없으면 빈 결과 메시지를 표시한다.
- 선택하지 않은 상태의 `코스에 추가` 버튼은 비활성화한다.
- `CourseMap`의 기존 SDK/경로 조회 실패 표시는 유지한다.

## 테스트

- 장소 검색: 이름·지역·태그 검색 및 빈 결과.
- 코스 추가: 마지막 정거장 추가, 중복 방지, 순번과 시간 계산.
- 지도 입력: 미리보기 정거장이 주어진 경우 활성 인덱스와 정거장 배열이 기대대로 구성되는지 확인.

## 범위

- 장소 검색 대상은 현재 정적 `PLACES` 데이터다.
- 추가한 동선은 화면 세션 동안만 유지되며 API 저장은 포함하지 않는다.
